# 06 · 隐私与成本

## 数据去了哪里

| 数据 | 去了哪 | 停留多久 |
|---|---|---|
| 会议转录文本 | 从你的 Drive 读出 → 发给 **Google Gemini API**（`generativelanguage.googleapis.com`）→ 返回纪要 | Gemini 侧：按 Google 的 API 数据政策；系统侧：压缩后的转录存在后台表里，任务完成 30 天后清空 |
| 录音文件 | 上传到 Gemini File API → 处理 → **任务结束立即删除** | 不依赖 Google 的自动过期 |
| 纪要 JSON | 后台表 `Tasks` 的 `result_json` 列（太长时存 Drive `MM_data/`） | 30 天后清空 |
| 生成的 Doc | 你的 Drive | 永久，直到你删 |
| 行动项 | 后台表 `Actions` | 永久 |
| 邮件 | 从你的邮箱发出，收件人见 03 | 由收件人决定 |
| Jira 评论 | 你的 Atlassian 站点 | 永久 |

**重点**：转录会离开公司的 Google Workspace，进入 Gemini API。**用之前请确认公司政策允许把会议内容送给第三方 AI 服务。**

用 AI Studio 的个人 API Key 时，Google 对免费额度的数据使用政策与付费不同（免费额度的数据可能被用于改进模型），请自行查阅 [Gemini API 服务条款](https://ai.google.dev/terms) 当前版本。

Gemini API Key 只存在脚本属性里，通过请求头发送，不进 URL、不进日志、不进代码。仓库里没有任何 Key。

## 谁能看到什么

| 东西 | 默认可见 | 能开放给谁 |
|---|---|---|
| 中文 Doc | **只有部署者**，永远 | 不能。系统不共享中文版；想给人看自己手动分享 |
| 英文 Doc | 只有部署者 | 项目组成员 / 订阅者 / 参会人 / 组织域 / 任何人（见 03） |
| 纪要邮件 | 只有部署者 | 订阅者（在场时）/ 组织者 / 全部参会人 |
| Jira 评论 | 能看那张票的人 | 评论只有标题 + 英文 Doc 链接 + 统计，没有正文；Doc 链接打不开就只是个链接 |
| 后台表 | 只有部署者 | 手动分享给需要改行动项状态的人。注意 `Tasks` 里有转录压缩文本和纪要 JSON |
| 周一汇总 | 只有部署者 | 不能 |

**设计原则**：收件人和共享对象**只来自这场会本身**（参会人、组织者、标题命中的项目）。没有「发给所有人」的全局列表。`MM_MAIL_POLICY=attendees` 和 `MM_DOC_SHARE=anyone` 存在但不推荐。

**共享是静默的**：Drive 共享不发通知邮件，Doc 不出现在别人的搜索结果里（域共享设了不可发现）。对方只能通过邮件或 Jira 里的链接进入。

## 部署者需要保护什么

| 东西 | 为什么 | 怎么做 |
|---|---|---|
| Gemini API Key | 泄露 = 别人花你的额度 | 只填脚本属性；不要截图发出去 |
| Jira API Token | 等于你的 Jira 身份 | 同上 |
| Apps Script 项目的编辑权限 | 有编辑权限的人能看所有脚本属性（包括 Key） | 不给任何人编辑权限；要分享代码就分享这个仓库 |
| 后台表格 | 含转录文本 | 只共享给确实需要改行动项的人 |
| `~/.clasprc.json`（用 clasp 的人） | 等于你的 Google 登录 | 换机器前 `clasp logout` |

## 成本

### Gemini

- 用的是 `gemini-3.6-flash`，Google 最便宜的一档。
- **免费额度**（AI Studio 默认）：个人用足够。一场 1 小时的转录约 1.5~2 万 token 输入 + 6~8 千 token 输出。免费档有每分钟 / 每天的请求上限，系统每 15 分钟最多调一两次 Gemini，个人用不会撞上。
- **付费 Key**：按 token 计费，1 小时会议不到 ¥0.1。要不要开付费看你对上面数据政策的态度。
- **系统自带熔断**：每月 1200「分钟」（约 20 小时会议），超了停处理只告警，下月自动恢复。`MM_MAX_MONTHLY_MINUTES` 可调。

### 录音比转录贵 7 倍

Gemini 听音频约 32 token/秒，1 小时录音 ≈ 11.5 万 token。能开转录就开转录，录音是兜底。

### Google Workspace 侧

Apps Script、Drive、Sheets、邮件都在你的 Workspace 配额内，不额外收费。限制：

| 配额 | 上限 | 系统用量 |
|---|---|---|
| 定时任务总运行时间 | 6 小时 / 天 | 每 15 分钟一次 × 最多 60 秒 ≈ 1.6 小时 / 天 |
| 邮件 | 1500 封 / 天（Workspace） | 每场会 1 封 + 偶发告警 |
| URL Fetch | 100 MB / 天 | 转录文本很小；录音每个 ≤ 50 MB，一天 2 个就到顶 |

### NewsAPI（仅附赠的财经日报）

免费档每天 100 次请求、新闻延迟 24 小时。日报每天 1 次请求，够用。
